# 测试用例

对照 [开发进度.md](开发进度.md)、[参考资料.md](参考资料.md)。前置：四个 Skynet 进程已开，客户端 `npm run dev` 在 5180，MySQL / Redis 可用。

标记：手工在浏览器走；对拍用命令行。预期里的文案以战报或界面提示为准。

## 1. 入口与登录

| 编号 | 步骤 | 预期 |
|---|---|---|
| 1.1 | 打开页面 | 停在菜单，只有「进入游戏」「人机测试」，不直接开战 |
| 1.2 | 进入游戏，名字空，点创建房间 | 提示要填名字 |
| 1.3 | 密码少于 4 位或超过 32 位 | 提示密码要 4 到 32 位 |
| 1.4 | 新名字 + 合法密码 | 建号成功，进大厅，CRING 50 万 |
| 1.5 | 已有密码的名字，密码填错 | 提示密码不对，进不了 |
| 1.6 | 已有密码的名字，密码填对 | 拿到原来的 uid，进大厅 |
| 1.7 | 以前没设过密码的名字，第一次填密码 | 密码定下来；再用错密码会被拒 |

## 2. 大厅与房间

| 编号 | 步骤 | 预期 |
|---|---|---|
| 2.1 | 大厅无人建房 | 列表显示还没有房间 |
| 2.2 | A 创建房间 | 列表出现该房，状态等待中 |
| 2.3 | B 点列表加入 | 两人同房；换边、换坦克、换地图会取消准备 |
| 2.4 | 只有红方有人，点开始 | 不可用或提示两边都要有人 |
| 2.5 | 红 1 蓝 2，点开始 | 提示双方人数必须相同 |
| 2.6 | 红蓝人数相同，有人没准备 | 提示还有人没准备 |
| 2.7 | 双方都准备，房主开始 | 进入对局；非房主不能开始 |
| 2.8 | 1v1 再加一名观战，双方准备后开始 | 可以开始；观战能看同一局，不用准备 |
| 2.9 | 观战座位已满到 8 人 | 不能再加入 |
| 2.10 | 对局中的房间 | 列表不可点加入 |
| 2.11 | 房主换丘陵/峡谷，换高度列/像素掩码 | 房间日志更新；预览地形跟着变；准备被清掉 |
| 2.12 | 人选坦克后开始 | 对局里是选中的种类、两发炮弹和射界 |
| 2.13 | 对局结束返回房间，再离开到空房 | 列表里该房消失 |

## 3. 人机测试

| 编号 | 步骤 | 预期 |
|---|---|---|
| 3.1 | 选丘陵 + 高度列，本地双人 | 开局；右上角或说明为高度列风格（平滑天际线） |
| 3.2 | 选峡谷 + 像素掩码，本地双人 | 开局；标「像素掩码」；可挖出洞 |
| 3.3 | 选坦克后对机器人（合法账号） | 联机开局，对面是 BOT |
| 3.4 | 轮到 BOT | 约 1.5 秒后可能移动/用药再开火；战报有 BOT 行动 |
| 3.5 | BOT 距离很远 | 会靠近若干步再打 |
| 3.6 | BOT 1 号打得到 | 用 1 号；打得到时才可能用双发 |
| 3.7 | 本地双人轮流 A/D、发射 | 同一浏览器两边都能操作 |

## 4. 回合、等待与倒计时

| 编号 | 步骤 | 预期 |
|---|---|---|
| 4.1 | 开局看 HUD | 显示剩余约 20 秒 |
| 4.2 | 等几秒再开炮 | 战报含「出手 N 秒，等待 +N×10」 |
| 4.3 | 立刻开炮（同一秒内） | 不加出手等待，只有炮弹等待 |
| 4.4 | 20 秒不开炮 | 「时间到，等待 +200」，跳过开炮，换手 |
| 4.5 | 移动一步 | 等待 +10，倒计时不重新从 20 开始 |
| 4.6 | 用道具 | 等待 +200，不交回合，倒计时不重置 |
| 4.7 | 普通弹 / 特殊弹 | 等待分别 +100 / +200（另加出手等待） |
| 4.8 | 第一轮 | 按座位轮流；之后等待低的先动 |

人机和房间对战都要覆盖 4.1–4.4。

## 5. 移动、射击与地形

| 编号 | 步骤 | 预期 |
|---|---|---|
| 5.1 | A/D 或按钮移动 | 位置变，燃料 −10，等待 +10 |
| 5.2 | 燃料耗尽再移动 | 提示燃料用完了 |
| 5.3 | 角度滑出射界 | 滑杆限制在射界内；非法角不能发射 |
| 5.4 | 预瞄黄点后发射 | 先播轨迹，再改地形和血量 |
| 5.5 | 高度列挖坑 | 天际线缺口，无顶棚空洞 |
| 5.6 | 像素掩码挖坑 | 可出现洞和洞壁草边；挡路的土走不过去 |
| 5.7 | 脚下挖空，落差 > 40 | 坠落伤害 |
| 5.8 | 正风力开火 | 落点偏右（相对无风） |

## 6. 特殊炮弹与状态

用对应坦克测。

| 编号 | 步骤 | 预期 |
|---|---|---|
| 6.1 | 叉叉毒箭打中活人 | 挂毒 3；该坦克自己回合开始 −20 |
| 6.2 | 毒跳满或毒死 | 战报有中毒 / 毒消了 / 中毒身亡一类字样 |
| 6.3 | 公爵毒气弹 | 当场伤害 + 毒云；云内到自己回合 −20；约 3 回合后散；换风后云平移 |
| 6.4 | 水鬼紫冻水 | 冻 2 个自己的回合：不能移动，还能开炮和用药 |
| 6.5 | 雷霆地雷落地 | 不挖坑不伤人；踩上去才炸，含自己 |
| 6.6 | 甲壳虫趴趴弹等三发弹 | 一次出手多发轨迹 |
| 6.7 | 海怪能量 ≤ 一半再开火 | 当发伤害提高 50%，战报可有半血加力 |

## 7. 道具、补给与结算

| 编号 | 步骤 | 预期 |
|---|---|---|
| 7.1 | 房间军火库买双发 | CRING 减少，库存增加 |
| 7.2 | 装备到出战格，对局中使用双发再开火 | 连续两发；道具等待 +200；炮弹等待只加一次 |
| 7.3 | 小补 | 回复约 20% 最大能量，之后还能移动 |
| 7.4 | 大补 | 回复约 40%，本回合不能再移动 |
| 7.5 | 满能量再治疗 | 提示能量已满 |
| 7.6 | 打中或开上补给箱 | 回复 25%；已满则不捡 |
| 7.7 | 房间对战胜方 | 按公式发 CRING；战报可有胜方每人 N CRING |
| 7.8 | 本地双人道具 | 不花 CRING；开局各带双发×3、小补×2、大补×1 |

## 9. 回归时优先

改协议、结算或倒计时后，至少再走：

1. 登录对错密码  
2. 建房 → 换地图与地形方式 → 两人准备 → 开始  
3. 人机一局：倒计时出手等待、时间到  
4. 高度列与像素掩码各开一炮  
5. 弹道对拍 8.2
