# 参考资料

这份目录是炮战演习的阅读地图。`Client` 和 `Server` 是自己写的，用来学回合制炮战和 Skynet 分进程。`Third/Atomic-Cannon` 是对照用的开源实现，不往 `Client` 里搬它的源码。坦克和房间规则按公开的《疯狂坦克2》资料复刻，不使用原作的客户端、贴图或私服代码。

## 怎么跑

1. 服务端：`Server\shell\start.bat`，或在 Cursor 里运行任务「Server: 开服」。  
   客户端只连 `ws://127.0.0.1:8090`。进入游戏要填名字和密码，4 到 32 位。新名字会建号。以前没设过密码的名字，第一次填写会把密码定下来。6801–6804 是四个进程之间的端口，不要对外。MySQL 3306 和 Redis 6379 只给 `dbApp` 用。  
   开服任务的终端会实时打出 db、gate、login、world 四份日志，关掉这个终端不会关服。同一份日志也写在 `Server\log`。  
   `stop.bat all` 和任务「Server: 关服」会结束本机所有 `skynet.exe`，包括别的工程。
2. 客户端：在 `Client` 里 `npm install`，然后 `npm run dev`。配置的端口是 5180；这个端口被占用时 Vite 会改用下一个空端口。
3. 页面先停在菜单。进入游戏进大厅。人机测试里才有对机器人和本地双人。

操作：鼠标按住拖动定角度，滑杆定力度，空格或「发射」开火。A / D 在本回合里挪坦克，每步扣燃料，也加等待值。← → 调角度，↑ ↓ 调力度。角度不能超出这辆坦克的射界。

## 弹道

对照的是 [ppizarror/Atomic-Cannon](https://github.com/ppizarror/Atomic-Cannon)（AGPL-3.0）里的线性风力弹道，数字取自它的 `src/core/CShot.ts` 和 `src/game/CGameController.ts`：

| 量 | 值 | 出处 |
|---|---|---|
| 重力 | 500 px/s²，向下 | `SHOT_GRAVITY` |
| 风力加速度 | 15 px/s² × 风力 | `SHOT_WIND_ACCEL` |
| 风力范围 | -5 到 5 | `MAX_WIND` |
| 力度 | 1 到 1000 | `POWER_MAX` |
| 初速 | 力度 × 武器系数 × √(画面宽 / 1000) | `launchSpeed` |
| 角度 | 0° 向右，90° 向上。蓝方把射界镜像到左侧 | `Vec2.fromAngle` |
| 积分 | 先加重力，再加风，再用新速度位移 | `CShot.update` |

正风力把炮弹推向画面右侧。每发打完换下一位，并重掷风力。

客户端同一套公式在 `Client/src/sim/rules.ts`，服务端在 `Server/dev/worldApp/rules.lua`。联机时只信服务端。

`Server/config/weapons.lua` 里还留着早先的四种通用炮弹（标准弹、重炮、集束弹、泥弹），只给弹道对拍用。对局玩家拿到的是自己那种坦克的两发。

## 房间

公开的新手说明写明：作战室最多 8 人，含观战；用 A–H 分队，同一字母同一队，OB 是观战；双方人数相等才能开始，因此最多 4 对 4。见 [新浪《疯狂坦克2》新手指南](http://games.sina.com.cn/zhuanqu/crazytank2/xinshou1.shtml)。

这里做成红、蓝两方，各最多 4 人。观战占一个座位，不计入两边人数，也不用准备。参战的人，包括房主，都要准备。人数不同、有一边没人、还有人没准备，开始会被拒绝。原作另外可以 8 人各自为战，这一局没有做。

## 12 种坦克

数字来自公开的坦克介绍，同一张表在 [中文百科「疯狂坦克II」](https://www.newton.com.tw/wiki/%E7%98%8B%E7%8B%82%E5%9D%A6%E5%85%8BII/12649906) 和玩家整理的 [12 种坦克列表](https://www.51yue.net/news/thread/20170703/10447805.html)。年代按介绍页的分组：古代大碗、叉叉、老土；近代甲壳虫、公爵、雷霆；现代飞火、流星；未来小妖、水鬼、闪灵、海怪。有一篇心得把雷霆算进未来系，这里跟介绍页，放在近代。

「破坏力 A\B」做成伤害和爆炸半径。发射角是朝自己前方的仰角，蓝方镜像。原作移动距离 60 换成现在的燃料 220，其余按比例取整。默认坦克是甲壳虫。

| 种类 | 系 | 能量 | 射界 | 等待 | 燃料 | 1 号炮弹 | 2 号炮弹 |
|---|---|---|---|---|---|---|---|
| 大碗 | 古代 | 950 | 0–90 | 560 | 183 | 巨石 350/45 | 火石 150/40 |
| 叉叉 | 古代 | 940 | 15–80 | 570 | 209 | 穿心箭 330/31 | 毒箭 100/28 |
| 老土 | 古代 | 920 | 25–45 | 580 | 176 | 铅球 140/78 | 小红豆 420/35 |
| 甲壳虫 | 近代 | 1000 | 0–40 | 560 | 220 | 骷髅弹 230/57 | 趴趴弹 150/38，三发 |
| 公爵 | 近代 | 1000 | 0–40 | 560 | 220 | 弹簧弹 240/55 | 毒气弹 153/43 |
| 雷霆 | 近代 | 1150 | 5–40 | 560 | 205 | 手榴弹 220/52 | 地雷 320/30 |
| 飞火 | 现代 | 1100 | 20–45 | 560 | 209 | 飞火弹 120/45 | 追魂弹 90/32 |
| 流星 | 现代 | 1050 | 25–50 | 570 | 202 | 三叉戟 175/40 | 流星雨 60/28，三发 |
| 小妖 | 未来 | 990 | 5–36 | 540 | 293 | 单雷炮 220/70 | 三雷炮 99/40，三发 |
| 水鬼 | 未来 | 1000 | 15–50 | 550 | 198 | 水水弹 230/54 | 紫冻水 190/43 |
| 闪灵 | 未来 | 970 | 20–55 | 550 | 257 | 离子弹 220/48 | 离子光波 270/66 |
| 海怪 | 未来 | 985 | 0–40 | 530 | 293 | 大电环 220/65 | 双发小电环 166/42，两发 |

多发只加在公开名字或攻略里写明了三连、双发的炮弹上：趴趴弹、流星雨、三雷炮、双发小电环。每发仍使用表上的伤害和半径。

等待值的算法来自同一篇玩家整理：第一轮顺序由座位决定，打完一轮才按等待值；普通武器 +100，特殊武器 +200。移动只公开了海怪大约每步 +10，这里每种坦克每步都 +10。相同等待值时，座位小的先动。

海怪在能量降到一半及以下时，当发伤害提高 50%。依据是攻略里写的「Power 会增加 50%」（[妖气游戏网的坦克简介](https://m.17u1u.com/zhanzheng/fktkdjb/1497348.html)）。同一篇后文又说破坏力增加两倍，两处不一致，这里采用写明了 50% 的那句。

毒、冰冻、地雷按公开现象单做，不按当场一炸结算。公开页面没有每跳伤害和持续回合，下面这几个数是这里定的。

- 毒箭打中爆炸范围内的坦克就挂毒，队友和自己也算。公开说法是「毒箭敌我皆上」。挂上后还剩 3 跳，每到这辆坦克自己的回合掉 20。再中一次刷新成 3 跳。当场仍先按表上的 100/28 结算。
- 毒气弹当场按 153/43 结算，并在落点留下同样半径的毒云。之后每个回合开始时，人在云里再掉 20。云存在 3 个回合。换风后按新风力平移，每点风力 12 像素。公开说明里人工降雨能消掉毒气，这里没有这件道具。
- 紫冻水当场按 190/43 结算。打中的人冻住 2 个自己的回合：不能移动，还能开炮、还能用药。公开地图心得只说冻住后不好脱身，没有写回合数。
- 地雷落地不挖坑、不伤人，留在地面上，谁踩上都炸，包括埋的人自己。炸开时用表上的 320/30。两颗叠在同一点会各炸一次。有人写满力双发可以打出 280×4，这里不采用这组数。

20 秒回合计时，以及计时带来的每秒等待 +10，没有做。暴龙在公开介绍里是随机隐藏坦克，能量和武器都是问号，所以没有放进表里。

## 军火库、补给箱、双发

作战室里的军火库对应公开说明里的 Ctrl+O 道具商店。货币叫 CRING。新手指南写明新号给 500,000，胜场奖励是 `{(X/2) + (Y×10,000)} / Z`：X 是这一局大家用掉的道具总价，Y 是参战人数，Z 是胜方人数。3 对 3、道具总值 240,000 时，胜方每人 60,000。见 [新浪新手指南](http://games.sina.com.cn/zhuanqu/crazytank2/xinshou2.shtml)。

出战最多 4 格，对应战斗热键 F9–F12。用一次道具，等待 +200，并且不结束这回合。依据是同一篇等待值说明：小妖不移动、双发再打特殊武器，等待按 540+200+200 累加。老土「双发小红弹」是 580+200+200，「双发铅球」是 580+200+100。所以双发是道具的 +200，炮弹仍按 1 号 +100、2 号 +200，两发只加一次炮弹等待。

| 道具 | 价格 | 效果 |
|---|---|---|
| 双发 | 20,000 | 这一炮连续打两发。第二发走第一发挖过的地形 |
| 小补 | 5,000 | 回复最大能量的 20%，之后还能移动 |
| 大补 | 12,000 | 回复最大能量的 40%，这一回合不能再移动 |

公开攻略只说小补回得少、用完还能走，大补回得多、用完不能走，没有写死比例和标价。上面的价格和 20% / 40% 是本项目定的。威力加强、防护罩、转移弹这局没做。

补给箱不是商店货。公开资料没有刷新表，这里每局在横向 280 和 680 的地面上各放一个。炮弹打中，或者坦克开上去，捡到的人回复最大能量的 25%。能量已经满了就不捡，箱子留在原地。本地双人不花 CRING，双方各带 3 个双发、2 个小补、1 个大补。

画面上的车身颜色是为了把 12 种区分开，不是原作造型。红蓝描边表示阵营。

## 协议

源文件在仓库根的 `Protocol/`。客户端拷贝在 `Client/public/protocol/`。开发服务器直接读 `Protocol/`。

| 名字 | tag | 方向 |
|---|---|---|
| rpcEcho | 0 | 网关本地回 |
| rpcAuthClient | 1 | 登录。名字加密码，密码不对就拒绝 |
| csJoinBattle | 2 | 人机测试。可带自己的坦克和机器人的坦克 |
| scState | 3 | 下推整局状态 |
| scResolve | 4 | 下推本次轨迹，末尾带新状态 |
| csFire | 5 | 角度、力度、炮弹 |
| csMove | 6 | -1 向左，1 向右 |
| scRoom | 7 | 下推房间。成员带队伍和坦克种类 |
| csCreateRoom | 8 | 创建房间 |
| csJoinRoom | 9 | 按房间号加入 |
| csSelectMap | 10 | 房主选丘陵或峡谷 |
| csReady | 11 | 准备或取消 |
| csStartGame | 12 | 房主开始 |
| csReturnRoom | 13 | 对局结束后回房间 |
| csLeaveRoom | 14 | 离开房间 |
| csSelectTeam | 15 | 红方、蓝方或观战 |
| scRoomList | 16 | 下推整份房间列表 |
| csEnterLobby | 17 | 订阅列表 |
| csLeaveLobby | 18 | 取消订阅 |
| csSelectBody | 19 | 在房间里换坦克 |
| scBag | 20 | 下推 CRING、库存和 4 个出战格子 |
| csBuy | 21 | 在房间里买入一件道具 |
| csEquip | 22 | 放进或卸下一个格子 |
| csUseItem | 23 | 对局里使用第几格 |

帧格式：一条 WebSocket 二进制帧是 `sproto.pack( .package 头 ++ 业务结构体 )`。`.package.ud` 不用。有 `type` 的是服务器推送，只有 `session` 的是请求的响应。`ok` 用整数 0/1。

## Skynet 怎么拆

结构照 `F:\maplestory\server\project`，运行时也从那里拷来。账号放在本机 MySQL 库 `fortress`，在线计数放在 Redis。

| MapleStory | 这里 | 做什么 |
|---|---|---|
| `etc/*AppConf` + `runconfig.lua` + `clustername.lua` | `Server/etc` | 四个进程，集群端口 6801–6804，网关 8090 |
| `dev/gateApp` | 同名 | WebSocket，按协议名转发 |
| `dev/loginApp` | 同名 | `rpcAuthClient`，向 dbApp 要 uid |
| `dev/dbApp` | 同名 | MySQL 账号、Redis 在线数 |
| `dev/worldApp/world.lua` | 同名 | 房间列表和订阅的人 |
| `dev/worldApp/battle.lua` | 同名 | 房间、对局、广播、机器人 |
| `dev/worldApp/rules.lua` | 同名 | 地形、弹道、伤害、等待值 |
| `dev/common` | 同名 | cluster、配置表、sproto |
| `config/*.lua` | 同名 | 常数、旧炮弹、12 种坦克、军火库道具 |
| `shell/start.bat` | 同名 | 拉起四个进程 |

`websocket.accept` 必须写在监听回调的同步调用栈里，不能 `skynet.fork`。跨进程调用服务名要带 `@`，见 `dev/common/cluster.lua`。

## 其他可以读的开源炮战

这些和《疯狂坦克2》不是同一个游戏，只是同一类：侧视、角度、力度、风、可破坏地面。

| 项目 | 协议 | 适合看什么 |
|---|---|---|
| [ppizarror/Atomic-Cannon](https://github.com/ppizarror/Atomic-Cannon) | AGPL-3.0 | 已克隆到 `Third/Atomic-Cannon`。弹道在 `src/core` |
| [masag0/Guntanks](https://github.com/masag0/Guntanks) | 仓库没有协议文件 | Gunbound / Worms 的短演示 |
| [CiaranMcCann/Worms-Armageddon-HTML5-Clone](https://github.com/CiaranMcCann/Worms-Armageddon-HTML5-Clone) | Apache-2.0 | TypeScript + Node.js 的回合同步 |
| [hedgewars/hw](https://github.com/hedgewars/hw) | GPL-2.0 | 完整游戏和专用服务器 |
| [bberberov/scorched3d](https://github.com/bberberov/scorched3d) | GPL-2.0 | 3D 炮战 |
| [crusadesoft/openartillery](https://github.com/crusadesoft/openartillery) | 页面标的是 Other | 浏览器联机和房间。先阅读 |
| [DigitalCyberSoft/scorchedearth-html5](https://github.com/DigitalCyberSoft/scorchedearth-html5) | 代码是重写，原版地形和语音不是开源部分 | 读 TypeScript，不要把 `public/assets` 里的原版文件再分发 |

Phaser 用的是 4.2（`phaser` 包）。场景在 `Client/src/game/BattleScene.ts`，只画高度图、坦克和轨迹，碰撞不交给物理引擎。
