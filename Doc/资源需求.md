# 资源需求

战场是 960×540。下面是地图、角色、特效、界面要交的图。程序现在仍用色块和高度列，这些文件放进 `Art/` 还不会自动进对局。不使用《疯狂坦克2》的原作贴图。

共通：PNG。文件名只用英文、数字和下划线。要挖、要叠在场景上的图带直通 alpha。半透明只留在边缘，大块半透明不要。放大绘制再缩小可以，参与碰撞的那一张必须是 960×540，1 像素对 1 个战场像素。

## AI 出图

提示词直接粘贴。生成图没有合格的透明通道，也落不到规定像素。统一放在纯品红 `#FF00FF` 上，出图后把这块颜色抠成透明，再缩到表里的尺寸。品红不要出现在要保留的物体上。

每条都接这句负向提示词：

```
text, letters, numbers, watermark, signature, frame, border, comic panels, photorealistic, blurry, red outline, blue outline, cast shadow covering the background, multiple objects
```

## 地图

一张地图交两张图，像素对齐。

| 文件 | 尺寸 | 内容 |
|---|---|---|
| `Art/map/hills_bg.png`、`Art/map/canyon_bg.png` | 1920×1080，贴上时缩到 960×540 | 天空和远山。不挡炮弹，不参与挖地 |
| `Art/map/hills_mask.png`、`Art/map/canyon_mask.png` | 正好 960×540 | 土层。不透明是土，透明是空和洞 |

掩码就是碰撞。炮弹停住的地方、挖掉的地方、画出来的土，是同一批像素。alpha 达到 128 算土。天空和洞不要填色，远山不要画进掩码。草是土块靠空一侧的边缘像素，洞的上沿、下沿和侧壁都会露出来。

`Art/map/map1.png` 是 1672×941 的 24 位图，没有透明通道。它可以当远景的画面参考。它不能当掩码：天空、远山和土层都是不透明颜色，也没有和战场对齐。

远景提示词。16:9。下缘约三分之一留纯品红，近景土层不要画，免得和掩码叠两层土。

## UI

界面现在是页面上的按钮和文字，不是贴图。中文用系统字体，不要做进图片里。

若改成图，按页面宽 960 出。按钮高约 32。面板用九宫格，四角固定、中间拉伸。每件交三态：常态、按下、不可用。

底色 `#1b2838`，边 `#3d5168`，字 `#f4efe6`，提示 `#ffe08a`，按下 `#8a5a2a` / 边 `#e0b15a`。

要覆盖的块：菜单、人机测试、大厅、房间（选坦克、地图、准备、军火库）、对局条（移动、角度、力度、炮弹、道具、发射）、结束。血条、风力文字、日志继续用程序画。

界面提示词。不要画出任何字。面板要能切九宫格：四角完整，四边是可横竖拉伸的直边。按钮三态各一张。

```
Flat game UI kit on a solid pure magenta background #FF00FF. One empty panel, fill #1b2838, 1-pixel border #3d5168, very small corner radius, straight top, bottom, left, and right edges so the frame can be sliced as a nine-patch. Under it, three empty buttons in a row, each about one quarter of the panel height: normal button fill #243140 border #3d5168; pressed button fill #8a5a2a border #e0b15a; disabled button the same shape at 45% opacity. No text, no letters, no icons, no photographs, no ornamental pattern filling the panel.
```
